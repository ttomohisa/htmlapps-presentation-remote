使い方と注意事項

PCで資料を開き、スマホをWebRTCリモコンとして接続します。

基本操作

  1. PCでPPTX / PDFを選択します。資料そのものは外部へアップロードされません。
  2. 「スマホを接続」から接続QRを作り、スマホ側で「スマホで操作」を選んで読み取ります。
  3. PCで「プレゼン開始」を押すと全画面表示になります。次へ・戻る・黒画面・ポインターはスマホから操作できます。
  4. スマホではPresenter Viewで現在・次スライドと発表者ノートを確認できます。大きな「次へ」ボタンと左右スワイプで移動し、ポインターはタッチ / モーションを切り替えられます。Presenter ViewのON/OFF、直接移動、タイマー、振動設定、切断は「その他」にあります。

プライバシー

PPTX / PDFは発表用PCのブラウザー内で処理します。スマホへ送るのは操作情報と、Presenter Viewで使う現在・次スライドの低解像度プレビュー、発表者ノートです。すべてWebRTCでPCからスマホへ直接送信します。シグナリングサーバー、STUN、TURNは使いません。

表示と接続の制限

  • PPTXはPowerPoint互換DOM/SVGレンダラーで端末内表示します。マスター/レイアウト、SmartArt、図形、テキスト、画像、表、グラフ等を再現しますが、アニメーション/画面切り替えは静止表示です。表示できない場合は互換レンダラーへ自動フォールバックします。互換性チェックも確認してください。
  • PDFはPDF.jsで端末内描画します。PDF本体を外部へ送らず、ページ単位でCanvasへ表示します。
  • 完全サーバーレス接続のため、基本的に同じWi-Fi / LANが必要です。ゲストWi-Fi、端末分離、VPN、ファイアウォール等では接続できないことがあります。
  • 全画面開始はブラウザーの制限によりPC側の操作が必要です。
