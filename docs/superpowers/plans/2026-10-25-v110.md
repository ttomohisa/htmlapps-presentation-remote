> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Implement the three approved improvements and prepare a verified v1.1.0 PR.
**Architecture:** Keep the standalone HTML architecture and existing WebRTC channels. Add host-authoritative completion results and timer state; square only the scanner guide.
**Tech Stack:** Vanilla JavaScript/HTML/CSS, Node tests, PowerShell builder, embedded pinned dependencies.
**Spec:** docs/superpowers/specs/2026-10-25-v110-design.md

## Global Constraints
- Only command feedback, presentation timer, square QR guide, v1.1.0 and required documentation/tests.
- No new networking services, dependencies, stored document/timer state, merge, tag, release, or production update.
- PC owns document/render/timer state. No automatic command resend.

## Review Focus
- Rapid navigation and late render completion must not generate a false applied result.
- Re-pairing or replacing the source must invalidate old pending results.
- Timer pause/reset and legacy peers must not keep extrapolating elapsed time.
- Editing duration while periodic state arrives must preserve the draft.
- Portrait/landscape camera frames must yield a contained, centered square guide.
